## PayPal tooling

Inspected [PayPal AI Toolkit](https://github.com/paypal/AI-Toolkit), its best-practices skill and authentication/checkout/webhook references, and [Agent Toolkit](https://github.com/paypal/agent-toolkit). Applied development guidance to backend REST Orders v2 calls. No PayPal MCP server is connected. Neither toolkit is a hidden runtime dependency, and no AI component receives capture tools. Redirect checkout follows the official Orders guide; a JS SDK dependency is unnecessary for this redirect flow.

## License boundary
