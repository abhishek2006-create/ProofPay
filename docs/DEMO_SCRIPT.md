# Demo — approximately 2 minutes 40 seconds

Use fictional seeded accounts. Open a client and freelancer in separate browser profiles. Prepare tests/fixtures/incomplete-homepage.txt, corrected-homepage.txt and gallery.json. The demo starts with an agreed milestone, but show the criteria version and both confirmations. If AI or PayPal remains unconfigured, disclose that limitation and omit any claim of a live integration.

- 0:00–0:20: Show the landing page and ambiguous scope problem. Explain explicit criteria and human acceptance.
- 0:20–0:45: Show the project, amount, due date, evidence requirements, version history and both parties' agreement. Demonstrate AI criteria proposals only if configured; otherwise show manual criteria with the unavailable notice.
- 0:45–1:15: Freelancer submits incomplete homepage text. Run actual artifact checks. Open the failed criterion and show source evidence and limitations. Explain that a text artifact check is narrower than browser functionality.
- 1:15–1:40: Client requests revision; freelancer uploads corrected text. Run checks again. Client reviews the linked result and explicitly accepts with rationale.
- 1:40–2:15: With credentials configured, client creates a sandbox order, buyer approves, client confirms capture and backend reconciles. Show the actual order/capture references. Without credentials, show the unavailable checkout state and explicitly state that live payment is not demonstrated. Never substitute a fabricated success.
- 2:15–2:40: Show audit history and evidence drill-down. Show actual test and evaluation output with scope limits. Explain that the buyer pays the configured sandbox merchant; there is no escrow or freelancer payout.
